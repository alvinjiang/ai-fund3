# Comps

Generate a comparables table with the company and its key global peers within the industry. Include the Bloomberg ticker, USD market cap, and the following valuation multiples: EV/Sales, EV/EBIT, P/E, and dividend yield. Also include the 5-year average return on equity for each peer. Any calculations and table generation should be performed in a spreadsheet, using the spreadsheet rules in the “Calculations” section below.
